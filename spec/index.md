# Grace

Grace helps an older adult handle email, appointments, saved photos and documents, ordinary browsing and bill payments while retaining control. The MVP uses `prototype/Grace Prototype.html` for presentation, with provider-neutral behavior. Say “Hey Grace” on a set-up Android tablet or tap Talk to start a voice exchange. A local keyword model detects the wake phrase. Conversation transcription, speech output and language inference use Grace Cloud. One Google sign-in creates her Grace account and connects that inbox. Grace ships as the Home launcher APK on stock Android, and release qualification requires a recorded Cuttlefish build and boot of an AOSP image with the same launcher. All product state and rules below are the source for generated code; the interface and the services around it are built on that code.

One meaningful question and current instruction remain understandable through speech, typing, corrections, manual website use and pauses. Website and message content supply evidence, never authority. Consequential submission requires current approval; only observed provider outcomes establish success. A pending or uncertain payment remains protected across every entry point and restart.
