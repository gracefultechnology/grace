# Grace

Grace helps an older adult handle email, appointments, saved photos and documents, ordinary browsing and bill payments while retaining control. The current rebuild uses `prototype/Grace Prototype.html` for presentation, including its enabled “Hey Grace” feature, and provider-neutral behavior. All product state and rules below are the source for generated code; external services and the interface are implemented in the following phase.

One meaningful question and current instruction remain understandable through speech, typing, corrections, manual website use and pauses. Website and message content supply evidence, never authority. Consequential submission requires current approval; only observed provider outcomes establish success. A pending or uncertain payment remains protected across every entry point and restart.
